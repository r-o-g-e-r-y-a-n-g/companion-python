# AI Companion (Google Cloud Customization)

This repository is a customized fork of [`weimeilin79/companion-python`](https://github.com/weimeilin79/companion-python), adapted and deployed as a working submission for an in-person Google technical workshop. 

The primary objective of this project was to take the existing architecture and successfully integrate, configure, and deploy it strictly within the Google Cloud ecosystem under workshop constraints.

## 🚀 Technical Implementations & Customizations

* **Google Search Grounding:** Configured the application to utilize real-time data retrieval via the Google ecosystem, anchoring model responses in search results to reduce hallucination.
* **Cloud-Native Environment Management:** Handled environment setup, dependency management, and local server testing natively using the **Antigravity CLI** within Google Cloud Shell.
* **CLI Deployment Pipeline:** Executed a complete Git version control restructure and deployment entirely via the Google Cloud Shell Terminal, establishing a clean fork-to-main merge history.

## 🛠️ Tech Stack & Environment

* **Base Architecture:** Python / Gemini Ecosystem
* **Development Environment:** Google Cloud Shell CLI
* **Testing/Server:** Antigravity CLI
* **Version Control:** Git
